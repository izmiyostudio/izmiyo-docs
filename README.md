## GitHub Pages kurulumu
1. Bu klasörün içeriğini repository köküne yükleyin.
2. Settings > Pages bölümünü açın.
3. Build and deployment kaynağında Deploy from a branch seçin.
4. Branch: main, folder: / (root) seçin.
5. Save ile yayınlamayı başlatın.
