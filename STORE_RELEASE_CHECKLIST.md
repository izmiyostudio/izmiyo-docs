# Mağaza Yayın Kontrol Listesi

## Geliştirici hesabında

- [ ] Uygulama adı, paket adı ve sürüm kodu eşleşiyor.
- [ ] Release AAB imzalı; debug signing fallback yok.
- [ ] Gizlilik URL'si ve destek e-postası çalışıyor.
- [ ] Türkçe ve İngilizce mağaza metinleri girildi.
- [ ] İkon, feature graphic ve 4–5 ekran görüntüsü yüklendi.
- [ ] İçerik derecelendirme anketi tamamlandı.
- [ ] Data Safety / App Privacy beyanları release davranışıyla doğrulandı.
- [ ] Hedef kitle ve çocuk/aile beyanları doğru seçildi.
- [ ] Reklam beyanı mevcut MVP için “reklam yok” olarak doğrulandı.
- [ ] Uygulama erişimi için özel test hesabı gerekmiyor.

## Yayın öncesi kalite

- [ ] Açılış, geri dönüş, tema ve dil değişimi test edildi.
- [ ] Boş liste, hata, uzun metin ve klavye durumları test edildi.
- [ ] Gizlilik ve şartlar bağlantıları uygulama içinden açılıyor.
- [ ] Bize Ulaşın ekranı izmiyostudio@gmail.com adresini gösteriyor.
- [ ] Hassas veri demo ekran görüntülerinden temizlendi.
- [ ] Android Auto/CarPlay iddiası yalnızca gerçek entegrasyon tamamlanınca yazıldı.
- [ ] Canlı backend, reklam veya satın alma etkinleşirse beyanlar yeniden kontrol edildi.

## Kalan kullanıcı işlemleri

- [ ] Google Play geliştirici hesabında mağaza formlarını doldur.
- [ ] Apple Developer hesabında iOS bundle ve App Store Connect kaydını aç.
- [ ] Gerçek cihazda son kabul testi yap.
- [ ] Gerçek ödeme, reklam ve backend kullanılacaksa ilgili hesapları bağla.
